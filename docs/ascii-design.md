# ASCII 動畫設計規格

參考使用者指定的 `ascii-skills`：`ascii-progress-and-spinner/GUIDE.md` 與 `ascii-terminal-animation-pack/GUIDE.md`。採用其固定寬度、已知／未知進度分離、低頻局部更新、純文字後備規則；原終端機指南的 ANSI／TTY 控制碼不帶入 GPUI。

## 小型樣式

| 狀態 | 影格 | 尺寸 | 換幀 |
| --- | --- | --- | --- |
| 同步／查詢 | `|` → `/` → `-` → `\` | 14×16px | 120ms |
| 遠端等待 | `.  ` → `.. ` → `...` | 28×16px | 240ms |
| 動態／投稿首頁載入 | `[=      ]` 至 `[      =]` 往返 | 76×16px | 120ms |
| 寫入／處理 | `[=..]` → `[.=.]` → `[..=]` → `[.=.]` | 42×16px | 240ms |
| 圖片／播放器載入 | `[>..]` → `[.>.]` → `[..>]` → `[.>.]` | 42×16px | 240ms |
| 有直播進行中 | `  .  ` → ` (.) ` → `((.))` → ` (.) ` | 42×16px | 720ms |

這些樣式均用 12px Consolas，保留空白字元並固定容器寬度。所有實例共用既有 120ms 時鐘，24 個時鐘步為完整共同週期；不增加每元件計時器、套件或外觀欄位。廣播提示每 720ms 換影格，並每 240ms 確認可見性，避免共用時鐘過早休眠。頁面／分組切換時的擦拭符號則是獨立的 240ms 過渡，減少動效、鍵盤導覽或停用 ASCII 時不顯示。

狀態動畫在工作完成、失敗或停止後移除；廣播動畫只在有直播進行時顯示。另有側欄小電視、各頁標題、未讀卡片與底部星點等純裝飾動畫。它們與狀態提示共用時鐘，畫面內容本身不位移。非作用中視窗停在目前影格，托盤／最小化時不推進；減少動效顯示靜態影格。取消「使用 ASCII 動畫」後，隱藏裝飾，載入使用一般圖示，直播狀態則顯示靜態圓點。

## 已知進度的三種字元方案

同為 50%，均為四格，無需顏色也能讀懂：

```text
[##..]  5/10
|==--|  5/10
(oo..)  5/10
```

實際採用第一種。批次新增以已完成結果數／輸入總筆數更新：成功、已存在、失敗都是已處理；待處理不計入。停止或重試後依目前結果重新計算。總數未知時顯示 `[....] --/--`，不推估 ETA 或顯示假百分比。

## 靜態參考影格

```text
|     sync
...   wait
[...] work
[>..] load
((.)) live

   \  /
  .-----.
  | o o |
  '-----'

```

## 無障礙與日誌後備

畫面以穩定的「處理中」、「載入中」或「有直播進行中」名稱描述動畫，不把每幀符號送成朗讀通知。批次進度的名稱提供實際已處理筆數。中文標籤與固定 ASCII 格子分開排版，不以字串長度推算中文字寬。

產品日誌不寫逐幀動畫、ANSI 色碼或回車覆寫；僅 debug 明確設定 `BILI_ASCII_TRACE=1` 時，另以可搜尋的完整紀錄行觀察時鐘。若未來提供 CLI：TTY 可以原行刷新；非 TTY、檔案重導向或停用動畫時只寫狀態改變的純文字，例如 `task=import processed=3 total=5`。目前沒有新增 CLI 動畫命令。
