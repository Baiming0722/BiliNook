## 最新更新：分組載入與 ASCII 對齊

動態首頁若回傳空清單，等待 500ms 後最多重試一次；仍為空且已有先前動態時，保留舊內容並顯示警告。真正沒有歷史資料時仍可能是正常空清單，空結果僅快取 5 秒，並提供重新整理提示。個別成員的較舊分頁失敗時保留已取得的內容、顯示重試提示；為避免遺漏項目，不產生無法確定排序的後續游標。切換不同成員或篩選條件會立即顯示新範圍的載入狀態。

參考專案根目錄的 `ascii-spinners-panel-switch.html`，動態及投稿首頁使用左右移動的 Pong 載入提示，切換分頁或分組時顯示 240ms 擦拭軌跡，不代表實際進度。減少動效、鍵盤導覽或停用 ASCII 時略過擦拭。側欄吉祥物改為四行、每行 11 字元的整體等寬繪製，眼睛會變化，不再將另一組軌道接在臉部下方。

- Workspace 91 項測試通過，涵蓋首次空回應恢復、連續空回應保留舊資料、單一成員分頁失敗、固定字寬及轉場影格。
- 使用兩位公開成員的隔離測試資料，實際切至「組別 1 VTuber」並載入動態；實際檢視一般／窄視窗及切頁擦拭、Pong 載入影格。上游回應可能不穩定，不能保證每次都能取回新資料。
- 新版 release 的雜湊與建置成品一致；上一版保存在 `.local/group-ascii-fix/`。其他電腦、長期運作與螢幕閱讀器未驗證。

## 先前更新：圖文動態與介面動畫

本次修正外層類型為圖文、實際主體為 `opus` 的動態解析；文字、圖片及可選預約資訊會依實際主體顯示。預約卡的「在 B 站查看」開啟原動態，不代替使用者送出預約。無可顯示內容時顯示提示，不再留下無說明的空白卡片。預約欄位僅增加於記憶體動態模型，舊資料沒有該欄位時預設為空，不變更追蹤存檔。

ASCII 動畫包含側欄眨眼小電視、動態頁波形、投稿頁膠卷、設定頁調節條、直播頁雷達、底部星點與前幾則未讀卡片的星光。裝飾不會逐幀送入無障礙樹；一般使用時持續播放，關閉「使用 ASCII 動畫」後隱藏。減少動效顯示靜態影格；失焦或隱藏時停止推進。

本次新增圖片／官方播放器載入時的連線軌道，以及有直播時出現在直播工作台和其他頁面側欄的廣播符號。廣播符號每 720ms 換幀；減少動效時固定為 `((.))`，關閉 ASCII 動畫時改為靜態圓點。播放器收合後重新開啟會重新顯示載入狀態。

同時修正直播預覽及新增監看按鈕的波紋：滑鼠事件改為先要求視窗重繪，後續影格才由繪製階段排程，避免在 GPUI 錯誤階段呼叫動畫影格而 panic。

參考使用者指定的 ascii-skills，以固定寬度、真實進度及低頻局部更新擴充現有小轉圈。保留「小型、易懂、分散多處」方向。沒有大型字元面板。完整影格、三種進度條方案、靜態參考及日誌後備見 [設計規格](ascii-design.md)。

## 樣式及位置

| 狀態 | 顯示 | 固定尺寸 |
| --- | --- | --- |
| 同步／查詢 | 單字元轉圈：`| / - \` | 14×16px |
| 載入／等待 | `.  `、`.. `、`...` | 28×16px |
| 動態／投稿初次載入 | `[=      ]` 至 `[      =]` 往返 | 76×16px |
| 寫入／處理 | `[=..]`、`[.=.]`、`[..=]` | 42×16px |
| 圖片／播放器載入 | `[>..]`、`[.>.]`、`[..>]` | 42×16px |
| 有直播進行中 | `  .  `、` (.) `、`((.))` | 42×16px |
| 批次實際進度 | `[##..]  3/ 5` | 四格加固定寬度筆數 |

狀態動畫涵蓋同步、載入、評論、圖片、播放器、直播新增、批次處理、設定儲存及安全退出；裝飾動畫另分布在側欄、各頁標題、未讀卡片及底部。多個可見元件共用同一個時鐘。

另有一處批次進度條，依實際結果更新。成功、已存在及失敗都算已處理，待處理不計入；停止後不跳成完成，重試時依目前結果重新計算。批次文字框自動保持 4–6 行並在框內捲動，十行輸入不再蓋住按鈕及進度列。

## 動效與控制

- 使用 12px Consolas，保留空白，容器不隨影格改變寬度。
- 共用既有 120ms 時鐘；轉圈每步、三點與處理／連線軌道每兩步、廣播符號每六步換幀。24 步為共同完整週期。
- 只有前景且有可見動態提示時推進；失去可見性後至多 360ms 寬限期便停止。非作用中視窗保留原影格。
- 工作完成、失敗或停止後移除其動畫；廣播符號在有直播時持續顯示。進度條沒有自行增加百分比或 ETA。
- 減少動效使用 `|`、`...`、`[...]`、`((.))` 靜態影格，真實進度及文字仍正常更新。
- 「直播工作台 → 設定 → 全程式外觀」取消「使用 ASCII 動畫」並儲存，可隱藏裝飾，並切回一般載入圖示與靜態直播圓點。實際進度資訊仍保留。

無障礙樹以穩定的「處理中」描述動畫，不逐幀朗讀符號；批次進度名稱包含實際已處理筆數。中文標籤與 ASCII 格子分開排版，不依賴色彩辨識狀態。未使用特定螢幕閱讀器完整驗收。
